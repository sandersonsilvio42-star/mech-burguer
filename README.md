# Mech-Burguer 🍔🍟

O **Mech-Burguer** é um projeto de cardápio digital e sistema de pedidos responsivo para uma hamburgueria, desenvolvido para simular uma experiência real de e-commerce e seleção de produtos.

A aplicação foca em uma interface dinâmica, intuitiva e atraente para o usuário, garantindo uma navegação fluida tanto em dispositivos móveis quanto em computadores.

## 🚀 Link do Projeto
Confira a aplicação rodando em produção: https://mechburguer.vercel.app/

## 🛠️ Tecnologias Utilizadas
* **HTML5:** Estruturação semântica de elementos do cardápio e seções.
* **CSS3:** Design responsivo, estilização moderna de componentes e efeitos visuais atraentes.
* **JavaScript:** Lógica de seleção de itens, cálculo de pedidos e dinamismo na interface.
